# Package composition

Design a package as a set of independent producers and systems, not a coordinated set of answer sheets.

## Variation matrix

Track each artifact across:

- producer and department;
- internal, external, or system origin;
- lifecycle and authority class;
- page, sheet, and row footprint;
- clean, lightly handled, actively worked, or executed state;
- typography, date format, filename convention, and print behavior;
- residue families and reviewer vocabulary.

## Evidence distribution

Place governing facts in the source that owns them. Use supporting files to decompose, corroborate, or complicate retrieval without restating the conclusion. Contextual files may describe intent or workflow. Incidental material may be present when the real process would carry it, but it must not create a competing authoritative answer.

## Package gate

Fail the package when unrelated producers share conspicuous quirks, all files have the same density, internal files are suspiciously thin, external files are implausibly informal, or combined marginal notes reveal the solution.
